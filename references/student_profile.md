# 学情档案：问卷全文与笔记风格映射

阶段 0 必须完成这份问卷。目的不是走形式 —— **没有学情就只能产出通用笔记**，而同样是 250 道刑法错题，一轮打基础和三轮冲刺需要的笔记完全不是一份东西。

## 一、问卷全文（用 AskUserQuestion 分两批问）

### 第一批：产出形态（必问）

**Q1 排版密度**
- 紧凑（推荐）—— 省纸，适合打印随身背。正文 9.3pt、行高 1.45、页边距 11/10mm
- 标准 —— 兼顾打印与屏幕。正文 10.5pt、行高 1.65
- 宽松 —— 适合平板上批注留白。正文 11.5pt、行高 1.9

**Q2 输出粒度**
- 每科一份 PDF —— 便于按科目分册携带
- 合成一本总册 —— 便于系统通读（带目录与书签）
- 两者都要（推荐）

**Q3 笔记侧重**
- 知识点梳理为主 —— 体系化，适合补基础
- 易错点辨析为主 —— 直面痛点，适合查漏
- 法条与期限速记为主 —— 数字、期限、机关权限的硬记
- 综合（推荐）

### 第二批：学情（强烈建议问）

**Q4 薄弱科目**（多选）—— 用于提高这些科目的易错点篇幅

**Q5 复习进度**
- 一轮打基础
- 二轮强化
- 三轮冲刺
- 考前一周

**Q6 每日可投入时长 + 学习习惯**
- 早晚碎片，每次约 30 分钟
- 每天 1–2 小时整块
- 周末集中大量
- 通勤刷题为主

补充可问（若用户愿意）：距考试天数、目标分数/过线。

### 用户说"别问了，直接做"时

采用全部默认值（紧凑 + 两者都要 + 综合），但**动手前用一句话复述确认**，例如：

> 那我按默认来：紧凑排版、每科一份 + 一本总册、内容综合侧重。开始抓取。

## 二、字段与笔记风格映射

| 字段 | 取值 | 对笔记的影响 |
|---|---|---|
| `layout` | 紧凑→`compact` / 标准→`normal` / 宽松→`loose`（json 写英文枚举） | 通过 CSS 变量控制字号、行高、页边距、表格密度（仅 `04_render_pdf.js` 读取） |
| `output_granularity` | 每科一份→`per_subject` / 合成一本→`volume` / 都要→`both` | 由主 Agent 据此决定渲染时是否给 04 传 `--volume`（04 也识别该字段，`--no-volume` 可显式取消总册） |
| `note_focus` | 梳理→`outline` / 易错→`traps` / 速记→`rules` / 综合→`comprehensive` | 决定每个知识点里"体系描述"与"易错辨析"的比例（json 存英文，**填进提示词时换中文释义**） |
| `weak_subjects` | 科目名数组 | 这些科目篇幅可放大到 1.3–1.5 倍，易错点写得更细；其余科目可压缩 |
| `review_round` | 一轮 / 二轮 / 三轮 / 考前一周 | 一轮补基础概念与体系；二轮重辨析与对比表；三轮只留高频结论与口诀 |
| `days_to_exam` | 数字 | ≤30 天时每科开头加「本阶段优先掌握 Top 5 知识点」 |
| `daily_minutes` | 数字 | 决定单科目标篇幅；时间少则更短更硬 |
| `study_habit` | 自由文本 | 碎片为主 → 短句、表格、口诀；整块为主 → 可保留体系化推演 |
| `target` | 自由文本 | 过线型强调必考规则；高分型保留争议点与例外 |

## 三、写入位置与格式

`<工作目录>/study_profile.json`：

```json
{
  "layout": "compact",
  "output_granularity": "both",
  "note_focus": "comprehensive",
  "weak_subjects": ["刑法", "刑事诉讼法"],
  "review_round": "二轮强化",
  "days_to_exam": 46,
  "daily_minutes": 90,
  "study_habit": "早晚碎片 + 周末整块",
  "target": "客观题过线"
}
```

缺失字段由 `scripts/lib/env.js` 的 `DEFAULT_PROFILE` 兜底，不会因缺字段而中断。

## 四、学情如何传递到笔记里

- **生成阶段**：填进 `assets/note_prompt_template.md` 的「学员情况」区块，让每个单元级 subagent 按此调整。
- **审查阶段**：填进审查员提示词，由 D5 维度（学员适配）核查是否落实。
- **修订阶段**：修订员若发现笔记与学情不符，按报告修正。

## 五、增量更新场景

考生第二次使用时，先读取已有 `study_profile.json`，只对**变化项**提问（例如"距考天数从 46 天变成 12 天，要不要把笔记改成冲刺版？"），不要重新问一遍全部问题。
